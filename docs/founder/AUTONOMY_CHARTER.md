# Founder Mode Autonomy Charter

## Default

Proceed autonomously with safe, reversible engineering inside this repository.

Routine implementation, local testing, fixtures, browser verification, and repair do not require feature-by-feature permission.

## Stop conditions

Stop only when progress requires:

- a real secret;
- a real external side effect;
- destructive production data handling;
- legal or monitored-zone activation;
- a production infrastructure change;
- a change to a locked safety or product boundary.

## Fixture status

When a real input is absent, use an anonymized, versioned fixture and label the result `fixture_verified`. Never claim `production_ready` until the real-source gate passes.
